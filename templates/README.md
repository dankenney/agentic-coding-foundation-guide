# Templates

Use whichever parts help with your task. You may only need a few sentences. Put the current task's status in a brief or handoff, and keep rules that apply across tasks in project instructions.

| Need | Start with |
|---|---|
| Define a change and what would prove it works | [Task brief](task-brief.md) |
| Give an agent stable repository guidance | [Project instructions](project-instructions.md) |
| Help someone resume paused work or take it over | [Handoff](handoff.md) |
| Capture guidance worth testing and reusing | [Lesson](lesson.md) |
| Decide which guide updates to accept | [Weekly review](weekly-review.md) |

Before sharing a completed template, remove credentials, private links, internal identifiers, and confidential context. Use made-up or approved public material in examples, and keep private sources in your private system.

For help using these, see the [worked task](../examples/worked-task.md), [first task](../guide/first-task.md), or [context guidance](../guide/context.md).

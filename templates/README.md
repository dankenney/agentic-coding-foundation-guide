# Templates

Copy the smallest useful part into your existing workflow. These are optional aids; a small task may need only a few sentences. Keep current state in a brief or handoff and durable rules in project instructions.

| Need | Start with |
|---|---|
| Define a change and what would prove it works | [Task brief](task-brief.md) |
| Give an agent stable repository guidance | [Project instructions](project-instructions.md) |
| Make a pause or transfer easy to resume | [Handoff](handoff.md) |
| Capture guidance worth testing and reusing | [Lesson](lesson.md) |
| Decide which guide updates deserve adoption | [Weekly review](weekly-review.md) |

Use synthetic or approved public material in shared examples. Remove credentials, private links, internal identifiers, and confidential context before sharing a filled template. Keep private provenance in your private system.

See a [worked task](../examples/worked-task.md), [first task](../guide/first-task.md), or [context guidance](../guide/context.md).

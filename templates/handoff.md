# Handoff

**Goal and current state:** What are you trying to complete, and what works now?

**Location:** Give the target project directory, branch/commit, relevant files, artifact paths, and backend/environment actually in use. Note uncommitted work and who owns it. Make clear which directory contains the project being changed and which contains the reference guide.

**Decisions:** Explain choices that affect the next step, or link to the decision records.

**Evidence:** Record the exact commands or interactions, actual results, and saved evidence. Mark proposed checks as unrun, and include live/UAT results where applicable.

**Unresolved:** Include reproduction steps, failures, assumptions, missing access, and checks you haven't run.

**Next action:** Give the next step, its expected result, and the authorization that covers it.

**Recovery:** Explain how to resume safely or undo the change.

The next reader needs enough to inspect the files and reproduce the evidence. Summarize what's relevant rather than pasting the whole transcript, and remove private data before sharing. For more on resuming work, see [recovery](../guide/recovery.md).
